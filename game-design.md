# GAME DESIGN

## Fantasy

Operate a machine in a huge underground world where valuable discoveries are hidden somewhere in the darkness.

## Core loop

EQUIP -> ENTER -> EXPLORE -> SCAN -> DIG -> DISCOVER -> MANAGE RISK -> EXTRACT -> UPGRADE -> RETURN

## Core differentiator

Depth is not the reward table.

The player is navigating a persistent physical world.

## Session

A session should include:
- starting context
- exploration
- uncertainty
- meaningful decisions
- resource management
- a reason to return or continue
- satisfying progress

## Risk

Fuel, durability, cargo, hazards and distance create tension.

## Rewards

Resources, discoveries, upgrades, achievements, seasonal progress and optional token utility.

## Rare discovery philosophy

Rare events should create stories, not just numbers.

## Failure

Failure should be recoverable. Avoid wiping entire mines or punishing experimentation excessively.
