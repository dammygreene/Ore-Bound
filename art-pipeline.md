# ART PIPELINE

Use GLB/glTF for 3D assets.

Prefer low-poly stylized models.

Asset categories:
- excavators
- machinery
- props
- geology
- UI
- effects
- audio

Example names:
excavator_starter.glb
rock_granite_a.glb
ore_gold_large.glb
artifact_compass.glb

Load assets by zone/chunk rather than everything at startup.
