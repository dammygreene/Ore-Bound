# UI / UX

## Principles

Game world first.
Information second.
Menus only when needed.
Touch-first interaction.
No hover-only controls.

## Mobile HUD

Top:
- fuel
- durability
- cargo

Bottom:
- movement
- dig/action
- scanner
- interact

Discovery notifications should not block controls.

## PC HUD

Compact HUD corners with keyboard shortcuts discoverable in help.

## Inventory

Show icon, name, quantity, cargo weight and rarity.

## Scanner

Show directional signals and intensity.

Do not reveal exact location unless scanner tier supports it.

## Surface

Garage, Mine, Refinery, Storage, Upgrade, Market, Leaderboard, Season.

## Accessibility

Support reduced motion, readable typography, high contrast, captions, keyboard navigation and color-independent indicators.
